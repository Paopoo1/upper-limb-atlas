# 上肢3D筋アトラス

右上肢の骨（3D プリント実習用モデルと同じデータ、紐を通す穴あり）に、筋と靱帯を付けた 3D ビューアです。

公開ページ: https://paopoo1.github.io/upper-limb-atlas/

## 使い方
- ドラッグで回転、ホイール／ピンチで拡大、右ドラッグ／2 本指で移動
- 筋や靱帯をタップすると、その 1 本だけを表示し、起始と停止のために開けた骨の穴が同じ色で光ります
- 「前から」「後ろから」などのボタンで視点を切り替えます

## ファイル
- `index.html` … ビューア本体（three.js r147 を CDN から読み込み）
- `bones.glb` … 骨のメッシュ（穴あり、面数を減らしたもの）
- `anatomy.json` … 筋・靱帯の走行、付着部（穴）の位置と穴の壁の面

## 出典
- 骨: NIH 3D の上肢モデル（右）を元に作成
- 筋・靱帯の走行は、実習用に簡略化したものです
